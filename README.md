# Syed Ghazi Raza Kazmi — Student Portfolio

A responsive, animated one-page student portfolio built with Next.js App Router, JavaScript, and Motion for React.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Files

- `app/page.js` — all one-page sections and interactions
- `app/globals.css` — responsive dark theme, layout, transitions, and animation styling
- `app/layout.js` — page metadata and root layout

## Notes

- The public contact details and education information follow the reference site supplied for this project.
- Copy buttons use the Clipboard API; if clipboard access is unavailable, they fall back to the appropriate email or phone action.
- Motion respects the user's reduced-motion preference.
